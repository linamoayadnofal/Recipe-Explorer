# Recipe Explorer – Project Description

**Recipe Explorer** is an interactive web-based platform designed to help users discover, explore, and organize recipes based on their food preferences and available ingredients.

The website provides users with an easy way to search for recipes by name or ingredient, explore different food categories, and view detailed recipe information, including ingredients and cooking instructions. Users can also save their favorite recipes and organize their weekly meals through a meal planner.

The system integrates external APIs to retrieve recipe data and Google search results, while using JSON to exchange and process data between the frontend and backend. It also uses an XML file to store recipe categories, which is parsed and processed by the backend.

The project is developed using **HTML, CSS, and JavaScript** for the frontend, with **Node.js and Express.js** for backend development.

### Main Features
- Search recipes by name or ingredient.
- Browse recipes by food category.
- View detailed recipe information and cooking instructions.
- Save and manage favorite recipes.
- Organize meals using a weekly meal planner.
- Discover random recipes.
- Search for additional recipe-related information.
- Contact form for user inquiries.

**Project Goal:** To provide a simple, user-friendly, and organized experience that makes discovering recipes and planning meals easier and more convenient.
